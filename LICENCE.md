## 🧩 About

**Counter-Strike 2 External Menu** is a curated list of Counter-Strike 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, radar overlay, menu
- **Quality-of-Life Helpers** — config manager, crosshair notes, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Practice config — load practice settings for offline study
- Radar overlay — external map radar for orientation
- Demo playback notes — review recorded matches
- Host timescale — adjust game speed in local server (0.1x to 5x)

### Wallhack
- Crosshair catalog — browse and save crosshair codes
- Skin notes — organize weapon skins locally
- Viewmodel config — adjust viewmodel settings

### Aimbot
- Config manager — save and load CFG files
- External menu — toggle overlay with hotkey
- Netgraph notes — custom netgraph settings
- Bunnyhop helper — configurable jump timing
